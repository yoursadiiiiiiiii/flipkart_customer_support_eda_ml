# Flipkart Customer Support Analysis & Customer Satisfaction Prediction

## 📌 Project Overview

This project analyzes customer support interactions and
builds machine learning models to predict customer satisfaction.

## 🎯 Objectives

- Analyze customer support data
- Identify major customer issues
- Study CSAT patterns
- Analyze response time
- Predict customer satisfaction

## 📊 Exploratory Data Analysis

The dataset contains 85,907 customer-support records.

Key areas analyzed:
- Support channels
- Issue categories
- Sub-categories
- Agent shifts
- CSAT scores
- Response time
- Customer satisfaction patterns

## 🤖 Machine Learning

Two machine learning models were implemented:

1. Logistic Regression
2. Random Forest

### Target Variable

CSAT 4–5 → Satisfied  
CSAT 1–3 → Not Satisfied

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📈 Model Evaluation

Models were evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC
- Confusion Matrix

## 💼 Business Impact

The model can help customer-support teams identify
patterns associated with customer satisfaction and improve
support operations.
